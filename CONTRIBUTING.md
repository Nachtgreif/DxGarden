# Rückmeldungen und Vorschläge

DxGarden wird in einem privaten Entwicklungs-Repository entwickelt. Dieses
öffentliche Repository dient den geprüften Veröffentlichungen und der offenen
Nachverfolgung von Rückmeldungen.

## Fehler und Vorschläge einreichen

Bitte verwende das passende Formular unter
[Issues](https://github.com/Nachtgreif/DxGarden/issues/new/choose). Ein neuer
Eintrag erhält zunächst den Status **Prüfung**.

Der öffentliche Ablauf lautet:

1. **Prüfung** – der Vorschlag oder Fehler wird nachvollzogen und bewertet.
2. **Angenommen** – die Änderung ist grundsätzlich beschlossen.
3. **In Arbeit** – die Umsetzung hat begonnen.
4. **Umgesetzt** – die Änderung ist fertig und erscheint unter `Unreleased` im
   Changelog.
5. **Veröffentlicht** – das Issue wird mit dem zugehörigen Release geschlossen.

Direkte Entscheidungen der Projektleitung können unmittelbar als
**Angenommen** eingetragen werden. Die Labels **Community** und
**Projektentscheidung** zeigen die Herkunft, nicht den Stellenwert der
Änderung.

Nur die Projektleitung ordnet Issues einem Versions-Meilenstein zu. Ein
Meilenstein zeigt damit, was für diese Version öffentlich eingeplant ist.

## Sicherheitsprobleme

Bitte veröffentliche vermutete Sicherheitslücken nicht als öffentliches Issue.
Nutze dafür einen privaten Kontaktweg zum Repository-Inhaber. Nach Behebung
kann die Änderung ohne gefährliche Einzelheiten im Changelog dokumentiert
werden.

## Quellcode

Dieses Repository nimmt keine Quellcode-Pull-Requests an, weil der private
Entwicklungsstand hier bewusst nicht veröffentlicht wird. Fehlerberichte,
Vorschläge und nachvollziehbare Tests sind willkommen.
